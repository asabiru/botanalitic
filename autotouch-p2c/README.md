# AutoTouch P2C Sniper

Скрипты AutoTouch для автоматизации P2P/P2C крипто-сделок на iOS (jailbreak).

Автоматически мониторит сделки в P2C криптоботе, быстро захватывает лучшие предложения и переходит в Озон Банк для оплаты.

---

## Возможности

- 🔍 **Мониторинг сделок** — непрерывное сканирование P2C бота через OCR + распознавание цветов
- ⚡ **Быстрый захват** — мгновенный тап на сделку (~50ms задержка)
- 💳 **Авто-оплата** — переход в Озон Банк и автоматическая оплата по ссылке или переводом на карту
- 🎯 **Фильтры сделок** — мин/макс сумма, метод оплаты, валюта
- 🔧 **Калибровка** — инструмент для настройки координат под ваше устройство
- 📊 **Статистика** — счётчик захваченных сделок, время, ошибки

---

## Требования

- iPhone/iPad с **jailbreak**
- **AutoTouch v7.0+** (JavaScript API)
- Telegram с открытым P2C ботом
- Озон Банк (приложение установлено)

## Установка

### 1. Установить AutoTouch

```
Cydia → Sources → Add: https://apt.autotouch.net
Cydia → Search → AutoTouch → Install
```

### 2. Скопировать скрипты на устройство

Способ A — через WebDAV:
```
1. Включить WebDAV Server в настройках AutoTouch
2. Подключиться с компьютера по указанному адресу
3. Скопировать папку autotouch-p2c/ в /var/mobile/Library/AutoTouch/Scripts/
```

Способ B — через Web Server:
```
1. Включить Web Server в настройках AutoTouch
2. Открыть указанный URL в браузере на компьютере
3. Загрузить файлы через веб-интерфейс
```

Способ C — через SSH (Filza):
```bash
scp -r autotouch-p2c/ root@<IP>:/var/mobile/Library/AutoTouch/Scripts/
```

### 3. Структура файлов

```
autotouch-p2c/
  config.js         — конфигурация (координаты, тайминги, фильтры)
  utils.js          — утилиты (tap, OCR, логирование)
  p2c_monitor.js    — мониторинг и сканирование сделок
  deal_grabber.js   — быстрый захват сделок
  ozon_pay.js       — оплата через Озон Банк
  main.js           — полный режим (мониторинг + захват + оплата)
  monitor_only.js   — только мониторинг (без захвата)
  grab_only.js      — мониторинг + захват (без авто-оплаты)
  calibrate.js      — инструмент калибровки экрана
```

## Первый запуск — Калибровка

**Обязательно** выполните калибровку перед использованием:

1. Откройте Telegram → перейдите в чат P2C бота
2. Запустите `calibrate.js` из AutoTouch
3. Просмотрите логи — там будут OCR-тексты и цвета экрана
4. Отредактируйте `config.js` — укажите правильные координаты для вашего устройства

### На что обратить внимание в config.js:

```javascript
device: {
  screenWidth: 430,   // ← ваша ширина экрана в points
  screenHeight: 932,  // ← ваша высота экрана в points
}
```

**Размеры экранов популярных iPhone (points):**
| Модель | Ширина | Высота |
|--------|--------|--------|
| iPhone 15 Pro Max | 430 | 932 |
| iPhone 15 Pro | 393 | 852 |
| iPhone 15 / 14 | 390 | 844 |
| iPhone SE 3 | 375 | 667 |
| iPhone 13 Mini | 375 | 812 |

## Режимы работы

### 1. Полный режим (рекомендуется)
```
Запустить: main.js
```
Мониторит → захватывает → оплачивает → возвращается в Telegram → повторяет.

### 2. Только мониторинг
```
Запустить: monitor_only.js
```
Только показывает уведомления о новых сделках. Для тестирования.

### 3. Захват без авто-оплаты
```
Запустить: grab_only.js
```
Захватывает сделки, но оплату нужно провести вручную.

## Настройка фильтров

В `config.js` секция `filters`:

```javascript
filters: {
  minAmountRUB: 1000,        // минимальная сумма в рублях
  maxAmountRUB: 100000,      // максимальная сумма в рублях
  minCryptoAmount: 10,       // минимум криптовалюты
  maxCryptoAmount: 10000,    // максимум криптовалюты
  maxSpreadPercent: 2.0,     // макс отклонение курса %
  acceptedPaymentMethods: ['Ozon', 'Озон'],  // принимаемые методы оплаты
}
```

---

## Настройка скорости

В `config.js` секция `timing`:

```javascript
timing: {
  scanIntervalUs: 300000,    // 300ms между сканами (↓ = быстрее, ↑ нагрузка)
  tapDelayUs: 50000,         // 50ms задержка после тапа
  betweenTapsUs: 100000,     // 100ms между тапами
}
```

> ⚠️ Слишком агрессивные настройки могут вызвать нестабильность. Начните с дефолтных значений.

---

## Безопасность

В `config.js` секция `safety`:

```javascript
safety: {
  maxDealsPerSession: 50,       // макс сделок за сессию
  cooldownAfterGrabUs: 2000000, // пауза после захвата (2с)
  maxConsecutiveErrors: 10,     // стоп после N ошибок подряд
  maxRunTimeMinutes: 120,       // стоп через 2 часа
}
```

## Устранение неполадок

| Проблема | Решение |
|----------|---------|
| OCR не распознаёт текст | Проверьте регион сканирования в config.js, запустите calibrate.js |
| Скрипт не находит кнопки | Обновите координаты в config.js для вашего устройства |
| Сделки не захватываются | Уменьшите scanIntervalUs, проверьте фильтры |
| Оплата не проходит | Убедитесь что Озон Банк установлен и залогинен |
| Скрипт остановился | Проверьте safety.maxConsecutiveErrors в логах |
