# AutoTouch P2C Sniper

Скрипты AutoTouch для автоматизации P2P/P2C крипто-сделок на iOS (jailbreak).

Автоматически мониторит сделки в P2C криптоботе, мгновенно захватывает лучшие предложения и переходит в Озон Банк для оплаты.

---

## Возможности

- **Мониторинг сделок** — непрерывное сканирование P2C бота (15ms pixel poll + OCR)
- **TURBO-захват** — мгновенный burst-tap на сделку (~8ms задержка, 3x тап)
- **Авто-оплата** — переход в Озон Банк и автоматическая оплата по ссылке или переводом на карту
- **Фильтры сделок** — мин/макс сумма, метод оплаты, валюта
- **3 режима скорости** — turbo / fast / safe
- **Калибровка** — инструмент для настройки координат под ваше устройство
- **Статистика** — счётчик захваченных сделок, время, ошибки

---

## Требования

- iPhone/iPad с **jailbreak** (iOS 16.2)
- **AutoTouch v7.0+** (JavaScript API)
- Telegram с открытым P2C ботом
- Озон Банк (приложение установлено и авторизовано)

## Пошаговая установка (от начала до конца)

### Шаг 1. Установить AutoTouch на устройство

Jailbreak уже стоит — нужно только поставить AutoTouch.

**Через Sileo / Cydia:**
```
1. Откройте Sileo (или Cydia)
2. Перейдите во вкладку "Источники" (Sources)
3. Нажмите "Добавить" (Add) и введите:
   https://apt.autotouch.net
4. Дождитесь обновления списка пакетов
5. Перейдите в "Поиск" (Search) и найдите "AutoTouch"
6. Нажмите "Установить" (Install) → "Подтвердить" (Confirm)
7. После установки нажмите "Перезагрузить SpringBoard" (Respring)
```

После respring AutoTouch появится в настройках iOS.

### Шаг 2. Активировать AutoTouch

```
1. Откройте "Настройки" → AutoTouch
2. Купите лицензию (или активируйте Trial)
3. Включите "Enable AutoTouch"
4. Включите "Web Server" — запомните показанный IP и порт (например: http://192.168.1.10:8080)
```

### Шаг 3. Скачать скрипты на компьютер

**Вариант A — через Git (если есть Git):**
```bash
git clone https://github.com/asabiru/botanalitic.git
cd botanalitic/autotouch-p2c
```

**Вариант B — скачать ZIP:**
```
1. Откройте https://github.com/asabiru/botanalitic
2. Нажмите зелёную кнопку "Code" → "Download ZIP"
3. Распакуйте архив
4. Найдите папку autotouch-p2c/ внутри
```

### Шаг 4. Загрузить скрипты на iPhone

**Способ A — через Web Server AutoTouch (самый простой):**
```
1. На компьютере откройте браузер
2. Введите адрес из шага 2 (например: http://192.168.1.10:8080)
3. Вы увидите файловый менеджер AutoTouch
4. Нажмите "Upload" (или "Загрузить")
5. Загрузите ВСЕ файлы из папки autotouch-p2c/:
   - config.js
   - utils.js
   - p2c_monitor.js
   - deal_grabber.js
   - ozon_pay.js
   - main.js
   - monitor_only.js
   - grab_only.js
   - calibrate.js
6. Убедитесь что все файлы лежат В ОДНОЙ ПАПКЕ на устройстве
```

**Способ B — через SSH (если знаете SSH):**
```bash
# Узнайте IP вашего iPhone: Настройки → Wi-Fi → (i) → IP-адрес
# Пароль по умолчанию: alpine

scp -r autotouch-p2c/ root@<IP_ВАШЕГО_IPHONE>:/var/mobile/Library/AutoTouch/Scripts/

# Пример:
scp -r autotouch-p2c/ root@192.168.1.10:/var/mobile/Library/AutoTouch/Scripts/
```

**Способ C — через Filza (прямо на iPhone):**
```
1. Скачайте ZIP из GitHub прямо на iPhone через Safari
2. Откройте Filza File Manager
3. Перейдите в: /var/mobile/Library/AutoTouch/Scripts/
4. Создайте папку "autotouch-p2c"
5. Скопируйте все .js файлы в эту папку
```

### Шаг 5. Калибровка (ОБЯЗАТЕЛЬНО перед первым запуском)

Координаты кнопок зависят от вашего конкретного устройства. Нужно настроить.

```
1. Откройте Telegram на iPhone
2. Перейдите в чат P2C бота
3. Откройте список сделок в боте (чтобы на экране были видны сделки)
4. Зажмите кнопку уменьшения громкости (или вашу Activator-комбинацию)
5. В панели AutoTouch выберите "calibrate.js"
6. Нажмите Play
7. Скрипт сделает скриншот и выведет в лог:
   - OCR-текст с экрана
   - Цвета ключевых точек
8. Проверьте логи: AutoTouch → Log View
```

### Шаг 6. Настроить config.js под ваше устройство

Откройте `config.js` через Web Server AutoTouch (в браузере) и измените:

**6.1. Размер экрана:**
```javascript
device: {
  screenWidth: 390,    // ← для iPhone 14 / 15
  screenHeight: 844,   // ← для iPhone 14 / 15
}
```

Таблица размеров (points):
| Модель | Ширина | Высота |
|--------|--------|--------|
| iPhone 14 Pro Max / 15 Pro Max | 430 | 932 |
| iPhone 14 Pro / 15 Pro | 393 | 852 |
| iPhone 14 / 15 / 13 / 12 | 390 | 844 |
| iPhone SE 3 / 8 | 375 | 667 |
| iPhone 13 Mini / 12 Mini | 375 | 812 |

**6.2. Координаты кнопок P2C бота:**

Используйте данные из `calibrate.js` логов. Или найдите вручную:
```
1. В AutoTouch откройте редактор скриптов
2. Нажмите "Extensions" → выберите любую функцию с координатами
3. Нажмите "HELPER" — появится перекрестие
4. Тапните на нужный элемент на экране
5. Координаты автоматически вставятся
```

Ключевые координаты которые нужно настроить:
```javascript
p2c: {
  buttons: {
    dealList: { x: 0, y: 200, width: 390, height: 500 },  // область списка сделок
    firstDeal: { x: 195, y: 250 },   // первая сделка
    acceptDeal: { x: 195, y: 600 },   // кнопка "Принять"
    confirmDeal: { x: 195, y: 700 },  // кнопка "Подтвердить"
    refresh: { x: 195, y: 160 },      // кнопка обновления
  },
  colors: {
    acceptButton: 0x34C759,  // ← цвет зелёной кнопки (из calibrate.js логов)
  },
}
```

**6.3. Режим скорости:**
```javascript
speedMode: 'turbo',   // 'turbo' | 'fast' | 'safe'
```

**6.4. Фильтры сделок:**
```javascript
filters: {
  minAmountRUB: 1000,
  maxAmountRUB: 100000,
  acceptedPaymentMethods: ['Ozon', 'Озон'],
}
```

### Шаг 7. Тестовый запуск (только мониторинг)

Сначала запустите в безопасном режиме, чтобы убедиться что всё работает:

```
1. Откройте Telegram → чат P2C бота → список сделок
2. Зажмите кнопку громкости (вызов панели AutoTouch)
3. Выберите "monitor_only.js"
4. Нажмите Play
5. Следите за логами — скрипт должен обнаруживать сделки и писать о них в лог
6. Чтобы остановить: зажмите кнопку громкости
```

Если мониторинг работает — переходим к полному запуску.

### Шаг 8. Полный запуск (мониторинг + захват + оплата)

```
1. Убедитесь что:
   - Telegram открыт, чат P2C бота на экране
   - Озон Банк установлен и вы авторизованы
   - config.js настроен
2. Зажмите кнопку громкости → выберите "main.js" → Play
3. Скрипт начнёт:
   - Сканировать экран каждые 15ms (turbo) / 200ms (fast)
   - При появлении новой сделки — мгновенно захватит её
   - Перейдёт в Озон Банк и оплатит
   - Вернётся в Telegram и продолжит мониторинг
4. Для остановки: зажмите кнопку громкости
```

## Режимы работы

| Скрипт | Что делает | Когда использовать |
|--------|-----------|-------------------|
| `main.js` | Мониторинг + захват + оплата | Основная работа |
| `grab_only.js` | Мониторинг + захват (без оплаты) | Когда хотите платить вручную |
| `monitor_only.js` | Только мониторинг | Тестирование и настройка |
| `calibrate.js` | Калибровка координат | Первая настройка |

---

## Режимы скорости

В `config.js` параметр `speedMode`:

| Режим | Сканирование | Задержка тапа | Burst-тапы | Для кого |
|-------|-------------|---------------|------------|----------|
| `turbo` | 15ms pixel poll | 8ms | 3x | Максимальная скорость, рискованно |
| `fast` | 200ms | 25ms | 2x | Баланс скорость/надёжность |
| `safe` | 500ms | 50ms | 1x | Стабильная работа, для начала |

> Рекомендация: начните с `safe`, убедитесь что работает, потом переключите на `turbo`.

## Настройка фильтров

```javascript
filters: {
  minAmountRUB: 1000,        // минимальная сумма в рублях
  maxAmountRUB: 100000,      // максимальная сумма
  minCryptoAmount: 10,       // минимум крипты
  maxCryptoAmount: 10000,    // максимум крипты
  maxSpreadPercent: 2.0,     // макс отклонение курса %
  acceptedPaymentMethods: ['Ozon', 'Озон'],  // только Озон
}
```

---

## Лимиты безопасности

```javascript
safety: {
  maxDealsPerSession: 50,       // макс сделок за сессию
  cooldownAfterGrabUs: 2000000, // 2с пауза после захвата
  maxConsecutiveErrors: 10,     // стоп после 10 ошибок подряд
  maxRunTimeMinutes: 120,       // авто-стоп через 2 часа
}
```

## Устранение неполадок

| Проблема | Решение |
|----------|---------|
| `calibrate.js` не видит текст | Убедитесь что P2C бот открыт и сделки видны на экране |
| Скрипт не находит кнопки | Запустите `calibrate.js`, обновите координаты в `config.js` |
| Сделки не захватываются | 1) Проверьте цвет `acceptButton` в config 2) Уменьшите `scanIntervalUs` |
| Оплата не проходит | Убедитесь что Озон Банк залогинен, есть деньги на счету |
| Скрипт остановился сам | Проверьте лимиты в `safety` или логи ошибок |
| "Script error" при запуске | Убедитесь что ВСЕ файлы в одной папке |
| Тап не регистрируется | Переключите `speedMode` на `safe` |
| AutoTouch не запускается | Проверьте лицензию, respring устройство |
