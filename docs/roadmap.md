## Найденные проблемы и исправления

### Исправлено в текущей версии:
1. **Yahoo Finance historical API** — `period2` передавался как `undefined`, что приводило к ошибке `InvalidOptionsError`. Исправлено добавлением `period2: new Date()`.

### Известные ограничения:
1. **X.com сентимент** — stub (заглушка), возвращает `null`. Требуется Twitter/X API key.
2. **Investing.com RSS** — может выдавать таймаут (10с). Не критично — есть fallback на Bloomberg RSS.
3. **yahoo-finance2 deprecated warning** — библиотека предупреждает о переходе с `historical()` на `chart()`. Работает, но стоит мигрировать.
4. **Нет unit/integration тестов** — тестирование проводится только через test-runner.
5. **Данные хранятся в памяти** — при перезапуске бота заказы и сессии теряются.

## Приоритетный план развития

### Этап 1 — OpenAI интеграция (1-2 недели)
**Цель:** Заменить шаблонный текст отчёта на генерацию через OpenAI

- [ ] Подключить OpenAI SDK (`openai` npm package)
- [ ] Создать `PromptBuilder` — формирует промпт на основе MarketContext
- [ ] Шаблоны промптов по типам активов (валюта, сырьё, акции, крипто)
- [ ] Structured output — JSON-схема для разделов отчёта
- [ ] Лимит токенов и cost tracking
- [ ] Fallback на текущий шаблон при ошибке OpenAI

### Этап 2 — X.com Sentiment API (1 неделя)
**Цель:** Реальный сентимент-анализ вместо заглушки

- [ ] Получить Twitter/X API key (Essential access)
- [ ] Реализовать поиск постов по ключевым словам инструмента
- [ ] Анализ тональности (NLP или через OpenAI)
- [ ] Агрегация score по выборке
- [ ] Кэширование результатов (TTL 10 мин)

### Этап 3 — Persistence и БД (1-2 недели)
**Цель:** Надёжное хранение данных

- [ ] PostgreSQL + Prisma ORM
- [ ] Таблицы: users, orders, payments, analysis_history
- [ ] Миграции
- [ ] Замена in-memory store на DB repositories
- [ ] История анализов пользователя

### Этап 4 — Подписки и алерты (2-3 недели)
**Цель:** Автоматические уведомления

- [ ] Утренний обзор рынка (ежедневная рассылка)
- [ ] Вечерний итог дня
- [ ] Алерты по уровням (пользователь задаёт цену — бот уведомляет)
- [ ] Подписка на инструмент — регулярные котировки
- [ ] Модель подписки (free/premium)

### Этап 5 — Улучшение графиков (1 неделя)
**Цель:** Более информативная визуализация

- [ ] Добавить SMA линии на график цены
- [ ] Добавить Bollinger Bands
- [ ] Candlestick (свечной) график как альтернатива
- [ ] Мини-график в котировке (sparkline)
- [ ] Интерактивные графики через TradingView widget (web)

### Этап 6 — Миграция yahoo-finance2 (0.5 недели)
**Цель:** Устранить deprecated warnings

- [ ] Заменить `historical()` на `chart()` API
- [ ] Добавить `suppressNotices` в конструктор

### Этап 7 — Качество кода (1-2 недели)
**Цель:** Надёжность и CI/CD

- [ ] ESLint + Prettier

5. **Группировка новостей** — по релевантности, а не по дате
